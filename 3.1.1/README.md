# 3.1.1 — Магнитометр

Заготовка отчёта (данных пока нет). Определяется горизонтальная составляющая
магнитного поля Земли $B_0$ (по отклонению стрелки в поле намагниченного
стержня и периоду крутильных колебаний стержня) и электродинамическая
постоянная $c$ (сравнение тока в единицах СИ и СГС).

```
3.1.1/
├── data/
│   ├── raw/          сырые данные — заполняются вручную во время работы
│   └── processed/    результат обработки — пишется скриптом, вручную не править
├── report/
│   ├── main.tex      отчёт
│   └── img/          фото установки (setup_photo.jpg), скан журнала (journal.jpg)
└── scripts/
    ├── lab_utils.py      общие утилиты (пути, МНК, округление, results.tex)
    └── process_data.py   обработка сырых данных
```

## Порядок работы

1. Во время лабораторной заполнить таблицы в `data/raw/` (строки с `#` —
   комментарии, номера измерений уже проставлены). Параметры установки и
   приборные погрешности — в `setup_params.csv`.
2. Обработка: `python scripts/process_data.py` — печатает все промежуточные
   и итоговые числа и пишет:
   - `data/processed/*_processed.csv` — таблицы для отчёта;
   - `data/processed/fit_results.csv` — сводка итоговых величин;
   - `data/processed/results.tex` — те же числа как макросы LaTeX.
3. Сборка: `cd report && latexmk -pdf main.tex`. Числа подставляются сами
   (`\res{Bzero}`, `\rese{c}` и т.п., ключи — столбец `key` в
   `fit_results.csv`); всё, чего ещё нет, выводится как **???**.
   Текстовые выводы помечены «?? НЕОБХОДИМО ЗАПОЛНИТЬ ??».
