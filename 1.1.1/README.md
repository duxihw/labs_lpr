# Лабораторная работа 1.1.1 — Изучение равноускоренного движения

## Структура папки

| Папка/файл        | Назначение |
|--------------------|------------|
| `report/`         | Отчёт по лабораторной работе в LaTeX (`main.tex`), собранный PDF и изображения для отчёта (`images/`) |
| `src/`             | Код на C++ (моделирование, расчёты, обработка больших объёмов данных) |
| `scripts/`         | Python-скрипты обработки данных и построения графиков |
| `data/raw/`        | Исходные (сырые) экспериментальные данные |
| `data/processed/`  | Обработанные данные, готовые для использования в отчёте |

## Как собрать отчёт

```bash
cd report
pdflatex main.tex
pdflatex main.tex   # второй проход для корректных ссылок/оглавления
```

## Как запустить обработку данных

```bash
cd scripts
pip install -r requirements.txt
python process_data.py
```

## Как собрать C++ часть

```bash
cd src
mkdir -p build && cd build
cmake ..
cmake --build .
./lab_1_1_1
```
