# 3.4.5 — Петля гистерезиса (динамический метод)

Отчёт заполнен данными измерений 20.10.2026: `report/main.tex` → `report/345.pdf`.
Таблицы, графики и все числа в тексте берутся из `data/processed/`, который
готовит скрипт обработки, — после правки `data/raw/*.csv` достаточно
перезапустить его и пересобрать PDF.

```
3.4.5/
├── data/
│   ├── raw/          данные из лабораторного журнала (строки с # — описание столбцов)
│   └── processed/    пишется скриптом, вручную не править
├── report/
│   ├── main.tex
│   └── img/
└── scripts/
    ├── lab_utils.py
    └── process_data.py
```

## Данные (`data/raw/`)

Все отсчёты по экрану — в **малых** делениях сетки (1 большое = 5 малых),
коэффициенты отклонения `Kx`, `Ky` — в мВ на **большое** деление.

| файл | пункт задания | что |
|------|---------------|-----|
| `setup_params.csv` | — | `R0`, `R_int` (кОм), `C_int` (мкФ), погрешность отсчёта |
| `samples.csv` | п.7 | материал, `N0/(2πR)` (1/м), `S·N_и` (см²) |
| `loops.csv` | пп.3–5 | предельные петли при наибольшем токе: `[2Xs]`, `[2Ys]`, `[2Xc]`, `[2Yr]` (двойные амплитуды) |
| `loops_screen.csv` | пп.4–5 | петли при 60 В на автотрансформаторе, `Xc`/`Yr` в увеличенном масштабе |
| `initial_curve.csv` | п.6 | вершины частных петель, координаты от центра (одинарная амплитуда) |
| `calib_x.csv` | п.9 | ток и длина развёртки при закороченной `N0` |
| `calib_y.csv` | п.10 | показание вольтметра и высота линии |
| `rc.csv` | пп.11–12 | размах сигнала на входе и выходе RC-цепочки |

## Обработка и сборка

```bash
cd 3.4.5
python scripts/process_data.py      # -> data/processed/*.csv, results.tex
cd report && latexmk -pdf main.tex
```
