## Что записать во время работы

| файл | пункт задания | что |
|------|---------------|-----|
| `setup_params.csv` | — | `R0`, `R_int` (кОм), `C_int` (мкФ) |
| `samples.csv` | п.7 | материал, `N0`, `N_i`, `S` (см²), `2πR` (см) для 3 образцов |
| `loops.csv` | пп.3–5 | `I_eff`, `Kx`, `Ky`, `[2Xs]`, `[2Ys]`, `[2Xc]`, `[2Yr]` (дел), площадь петли (необяз.) |
| `initial_curve.csv` | п.6 | 8–10 вершин частных петель на образец: `Kx`, `Ky`, `[2X]`, `[2Y]` |
| `calib_x.csv` | п.9 | для **каждого** использованного `Kx`: ток и длина развёртки при закороченной `N0` |
| `calib_y.csv` | п.10 | `Ky`, показание вольтметра, высота линии |
| `rc.csv` | пп.11–12 | `U_вх`, `U_вых` RC-цепочки |

Все размеры на экране — **полные** (двойные амплитуды), в делениях сетки.
Если для какого-то `Kx` калибровки нет, цена деления пересчитывается
по `R0`, найденному из калибровки остальных `Kx`.

## Обработка и сборка

```bash
cd 3.4.5
python scripts/process_data.py      # -> data/processed/*.csv, results.tex
cd report && latexmk -pdf main.tex
```

После сборки поиском по `НЕОБХОДИМО ЗАПОЛНИТЬ` найти места, где нужен
текст (выводы, модель осциллографа и т.п.), и заполнить справочные
значения в табл. «Сравнение со справочными данными».
