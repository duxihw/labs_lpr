## Порядок работы

1. Во время лабораторной заполнить таблицы в `data/raw/` (строки с `#` —
   комментарии с описанием столбцов).
2. Обработка:

   ```bash
   cd 3.3.4
   python scripts/process_data.py   # -> data/processed/*.csv, results.tex
   python scripts/plot_data.py      # -> report/images/*.pdf
   ```

   `process_data.py` печатает все промежуточные числа и пишет их в
   `data/processed/fit_results.csv`, а в виде LaTeX-макросов (`\ResRH`,
   `\ResN`, `\ResMu`, …) — в `data/processed/results.tex`, который
   подключается из `main.tex`. Переносить числа руками не нужно.
3. Сборка отчёта: `cd report && pdflatex main.tex && pdflatex main.tex`.

## Что считает обработка

* `B(I_M)` — кусочно-линейная интерполяция градуировки (при милливеберметре
  `B = Φ/(SN)`);
* `U⊥ = U34 − U0`; для каждой серии МНК-наклон `k = dU⊥/dB`;
* наклон `K = dk/dI`, постоянная Холла `R_H = K·h`, концентрация
  `n = 1/(e|R_H|)`; погрешность `R_H` включает σ_K, σ_h и ε_B;
* контроль обращением поля: `U⊥ = (U⁺ − U⁻)/2`, омическая добавка
  `(U⁺ + U⁻)/2`;
* `ρ0 = U35·a·h/(I·l)`, `σ0 = 1/ρ0`, подвижность `μ = σ0·|R_H|` в см²/(В·с);
* оценки к контрольному вопросу 6: частота столкновений, длина пробега,
  коэффициент диффузии (`T_K` и `m_eff` задаются в `setup_params.csv`).

Знак `R_H` в выводе скрипта — в системе отсчёта установки (как подключён
вольтметр); тип проводимости определяется по рисунку в тетради (п. 9).
