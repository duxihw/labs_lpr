# 3.3.4 — Эффект Холла в полупроводниках

Опыт выполнен 23 ноября 2026 года. Автор — Емельянов Дмитрий Алексеевич, группа Б02-502. Готовый отчёт находится в [report/334.pdf](report/334.pdf).

| Файл в data/raw | Содержание |
|---|---|
| calibration.csv | 16 изменений потокосцепления от нуля в мВб и соответствующие токи магнита в А |
| hall_series.csv | Ток образца и знаковый нуль для восьми прямых серий |
| hall.csv | 61 ненулевой отсчёт в прямом поле. Напряжение первой серии в мВ, остальных в мкВ |
| hall_reverse.csv | Обратная серия при 0,9 мА, включая собственный нуль, напряжение в мкВ |
| resistivity.csv | Начальный и конечный отсчёты продольного напряжения при 0,9 мА |
| setup_params.csv | Толщина, ширина, расстояние между контактами и произведение площади катушки на число витков |

Из папки работы выполнить:

```bash
python scripts/process_data.py
cd report
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Обработка записывает таблицы и результаты в `data/processed/`, четыре векторных графика — в `report/img/`. LaTeX собирает `report/main.pdf`. При сборке проектным скриптом `bash .github/scripts/build_reports.sh 3.3.4` из корня результат получает имя `report/334.pdf`.

Поле вычисляется по формуле $B=|\Delta\Phi|/(SN)$ с кусочно-линейной интерполяцией градуировки. Для каждого тока образца из поперечного напряжения вычтен свой нуль. По наклону зависимости $K(I)$ найден модуль постоянной Холла. Продольный расчёт использует среднее двух отсчётов и половину их размаха в погрешности. Результат проверки обращением поля, чувствительность к двум прочтениям журнала и условия определения знака носителей приведены в обсуждении отчёта.
