\section{Аннотация}
Цель работы --- исследовать свободный отклик электрического контура и его отклик на синусоидальное возбуждение. По периоду при разных ёмкостях проверяется формула Томсона. По изменению затухания с сопротивлением определяется граница колебательного режима. Для двух сопротивлений сравниваются оценки добротности по параметрам цепи, свободному затуханию, резонансным кривым и переходным процессам.
\section{Теоретические сведения}
Пусть $C=C_{\textrm{маг}}+C_0$ --- полная ёмкость, $R_\Sigma=R+R_L$ --- сумма сопротивлений магазина и обмотки. Между импульсами конденсатор разряжается через катушку и резистор. Из закона Кирхгофа для заряда $q=CU_C$ следует
\[
 \ddot q+2\gamma\dot q+\omega_0^2q=0,\qquad
 \gamma=R_\Sigma/(2L),\quad \omega_0=(LC)^{-1/2}.
\]
При $\gamma<\omega_0$ напряжение равно $Ae^{-\gamma t}\cos(\omega_dt+\alpha)$, где $\omega_d=\sqrt{\omega_0^2-\gamma^2}$. Период $T_d=2\pi/\omega_d$ при слабом затухании близок к $T_0=2\pi\sqrt{LC}$. При $R_\Sigma=R_{\textrm{кр}}=2\sqrt{L/C}$ корни характеристического уравнения совпадают, при большем сопротивлении разряд апериодический.
\[
 \Theta=\gamma T_d=\frac1n\ln\frac{|U_k|}{|U_{k+n}|},
 \qquad Q=\frac{\omega_0}{2\gamma}=\frac{1}{R_\Sigma}\sqrt{\frac LC}.
\]
Величина $\pi/\Theta=\omega_d/(2\gamma)$ приближает $Q$ при слабом затухании. На фазовой плоскости $X=U_C$, $Y=RI\propto\dot U_C$ траектория образует спираль. Одноимённые пересечения одного луча отстоят на целое число периодов, поэтому отношение их расстояний от центра даёт тот же декремент.
\par При гармоническом возбуждении в модели осциллятора с постоянной амплитудой силы правая часть уравнения пропорциональна $\cos\omega t$. Амплитуда и фаза установившегося отклика имеют вид
\[
 U_C\propto[(\omega_0^2-\omega^2)^2+4\gamma^2\omega^2]^{-1/2},
 \quad \varphi=-\operatorname{atan2}(2\gamma\omega,\omega_0^2-\omega^2).
\]
Максимум амплитуды приходится на $\sqrt{\omega_0^2-2\gamma^2}$, а запаздывание на четверть периода --- на $\omega_0$. При включении цуга на резонансе в приближении слабого затухания огибающая растёт как $U_0(1-e^{-\gamma t})$, после выключения спадает как $U_{\textrm{кон}}e^{-\gamma t}$.

Если плато не достигнуто, измерить $U_0$ при непрерывном возбуждении той же амплитуды. При $R_1$ отстроить частоту и записать биения. После отключения установки измерить $R_L$ и $L$ на частотах 50, 500 и 1500~Гц.

\paragraph{Периоды (п. 2.7.1).} $T_{\textrm{эксп}}=\Delta t/n$, $C_0=T_{\textrm{эксп}}^2(0)/(4\pi^2 L)=\res{Czero}$~нФ. По семи точкам методом наименьших квадратов получена прямая $T_{\textrm{эксп}}=kT_0+b$, где $k=\res{periodSlope}$ и $b=\res{periodIntercept}$~мкс. Для формулы Томсона ожидаются $k=1$ и $b=0$. Для независимых отсчётов $u(T_{\textrm{эксп}})=u(\Delta t)/n$. При подстановке $C_0$ удобно считать $T_0=\sqrt{T^2(0)+4\pi^2 LC_{\textrm{маг}}}$, чтобы учесть общий параметр $L$ один раз. Нулевая точка задаёт калибровку.
\paragraph{Критическое сопротивление (пп. 2.7.2--3).} Для свободного разряда построить $Y=1/\Theta^2$ от $X=1/R_\Sigma^2$. Из уравнения контура $Y=aX-1/(4\pi^2)$, $a=R_{\textrm{кр}}^2/(4\pi^2)$. По наклону линейного участка у начала координат $R_{\textrm{кр}}=2\pi\sqrt a$, $u(R_{\textrm{кр}})=\pi u(a)/\sqrt a$. Свободная МНК-аппроксимация $Y=aX+b$ по семи точкам даёт $a=\res{criticalSlope}$~Ом$^2$ и $b=\res{criticalIntercept}$. Погрешности параметров обеих прямых оценены по разбросу остатков. Результат по наклону: \res{criticalFit}~Ом; по параметрам $L,C$: \res{criticalTheory}~Ом; по границе режимов $R_{\textrm{переход}}+R_L$: \res{criticalObserved}~Ом.
\paragraph{Свободный разряд и спираль (пп. 2.7.4--6).} По крайним декрементам и координатам витков вычислить $Q=\pi/\Theta$. Для независимых амплитуд\[u(\Theta)=\sqrt{[u(U_k)/U_k]^2+[u(U_{k+n})/U_{k+n}]^2}/n.\]Для сравнения вычислить $Q$ по $L,C,R_\Sigma$ с указанием частоты измерения катушки.
\paragraph{Резонансные кривые (пп. 2.7.7--10).} Совместить АЧХ для двух сопротивлений в координатах $U_C/U_{\textrm{рез}}$ и $\nu/\nu_{\textrm{рез}}$. Линейно интерполировать частоты пересечения уровня $1/\sqrt2$ на обоих склонах. Оценка при узком резонансе $Q_{\textrm{А}}=\nu_{\textrm{рез}}/(\nu_+-\nu_-)$. Построить обе ФЧХ в координатах $(\omega,\varphi)$. Отразить часть ниже $-\pi/2$ по правилу $\varphi'=-\pi-\varphi$. Ширина между пересечениями уровня $-\pi/4$ равна разности частот исходной кривой при $-3\pi/4$ и $-\pi/4$. Тогда $Q_{\varphi}=\omega_{\varphi=-\pi/2}/\Delta\omega$.
\paragraph{Оцифровка видео.} Для $R_1=410$~Ом использована запись IMG\_2494.MOV. После выравнивания перспективы обоих дисплеев настройки генератора разделены по изменению выделенного разряда (10~Гц). Опорные показания прочитаны на дисплее, промежуточные распознаны с учётом монотонного вращения ручки и периода синей трассы. Для 168 различимых настроек сохранено по одному кадру. Из-за размытия младшего разряда частота отдельных точек может отличаться на один-два шага.
\par Для каждого цвета по пикселям трассы построена синусоида. Размах жёлтой синусоиды делится на наибольший размах видеосерии ($\res{peakV1}$~В при $\res{peakFreq1}$~Гц). Время отсчитывается вправо: $\Delta t=t_{\textrm{жёлт}}-t_{\textrm{син}}$ для ближайших максимумов, $\varphi=-2\pi\nu\Delta t$. Жёлтые максимумы на записи расположены левее синих, поэтому измеренная фаза положительна. На этой ветви берём ширину между уровнями $3\pi/4$ и $\pi/4$, центральную частоту --- на уровне $\pi/2$. Это те же уровни относительно середины фазового перехода, что и в методике. Для второго сопротивления в записи отдельного частотного прохода нет.
\paragraph{Цуги и биения (п. 2.7.11).} На участке роста использовать
$\Theta=n^{-1}\ln[(U_0-U_k)/(U_0-U_{k+n})]$, на спаде --- формулу свободного разряда. Сопоставить оценки $\pi/\Theta$. При отстройке свободная составляющая на частоте $\nu_d$ складывается с вынужденной на частоте $\nu$. Ожидаемый интервал максимумов огибающей $1/|\nu-\nu_d|$ сравнить с видеозаписью, учитывая затухание свободной составляющей.

\paragraph{Погрешности и сопоставление (пп. 2.7.12--13).} Для результата $F$ использовать $u^2(F)=\sum_{ij}(\partial_i F)(\partial_j F)\operatorname{cov}(x_i,x_j)$. Относительная погрешность равна $100u(Q)/Q$.

\section{Обсуждение и заключение}
Период при увеличении ёмкости магазина от 0 до 9~нФ вырос от 67,2 до 199,7~мкс. При обработке использованы параметры катушки на частоте 1500~Гц ($L=100{,}04$~мГн, $R_L=23{,}110$~Ом) --- ближайшей к рабочей из трёх измеренных. Для свободного затухания ёмкость магазина равнялась 6~нФ, полная ёмкость около 7,14~нФ. При увеличении $R$ от 410 до 2000~Ом добротность по декременту уменьшилась с $\res{free1}$ до $\res{free2}$. Значение критического сопротивления по прямой, построенной по семи точкам, ближе к расчётному значению, чем визуальная оценка перехода.
\par Перед снятием резонансных кривых ёмкость магазина уменьшили до 5~нФ. При $R_1=410$~Ом зарегистрирован максимум на 6420~Гц с размахом 20,2~В. Журнал указывает диапазон видеосъёмки 5500--7500~Гц. По видео максимум размаха составляет $\res{peakV1}$~В при $\res{peakFreq1}$~Гц. Ширины амплитудной и фазовой характеристик дают близкие оценки добротности $Q_{\textrm{АЧХ}}=\res{ach1}$ и $Q_{\textrm{ФЧХ}}=\res{phase1}$. Для величин из журнала инструментальные погрешности пока не установлены.
