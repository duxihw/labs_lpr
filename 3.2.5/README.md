| Файл в data/raw | Что записывать |
|---|---|
| periods.csv | Ёмкость магазина (нФ), число периодов, интервал времени (мкс). Обязательна нулевая настройка. |
| pairs.csv | Сопротивление и пары пиков для free, spiral, rise, fall. Для спирали брать расстояния от центра, для роста заполнить U0. |
| resonance.csv | Отдельная серия для каждого R, частота (Гц), размах (В), запаздывание выхода (мкс). |
| lcr.csv | Индуктивность (мГн) и активное сопротивление (Ом) на каждой частоте LCR-метра. |
| setup_params.csv | R1, R2, сопротивление перехода, погрешность магазина (Ом), фактическая установка ёмкости и её погрешность (нФ), частота выбранной строки LCR (Гц). |

Поля с префиксом s содержат стандартные погрешности. Указать их перед итоговым расчётом. Фотографии и кадры видео положить в report/img под именами из подписанных рамок отчёта.

Из каталога работы запустить `python scripts/process_data.py`, затем `latexmk -cd -pdf report/main.tex`. Скрипт получает период из интервала между пиками, декремент из отношения амплитуд, критическое сопротивление из наклона зависимости обратных квадратов, а ширины резонанса линейной интерполяцией. Инструментальные погрешности распространяются численным моделированием. После ввода данных проверить выбор линейного участка, оценить разброс повторов и сверить погрешности с паспортами приборов.

Оцифровка HEIC: python scripts/digitize_photos.py <каталог фотографий> (Pillow, SciPy, heif-convert). Координаты экстремумов и полуразмахи записаны в data/raw/image_peaks.csv. Таблица исходных амплитуд из журнала — data/raw/journal_decay.csv.

Видеопроход IMG_2494.MOV: запуск `python scripts/digitize_video.py <путь-к-видео> <рабочая-папка>` (OpenCV, NumPy, SciPy, pandas). В рабочей папке сохраняются отсчёты по кадрам, фрагменты дисплея и выбранные полные кадры. В data/raw/video_resonance.csv записаны частота, размах CH1 и задержка ближайшего максимума CH1 относительно синего CH2, номер кадра от нуля и время в секундах. При размытии младшего разряда учитываются опорные показания генератора и период синей трассы; отдельные частоты приближённые. Независимый максимум из журнала сохранён в resonance.csv. МНК-прямые рис. 5 рассчитываются скриптом вместе с ошибками коэффициентов.
