# 3.1.3 — Измерение магнитного поля Земли

Заготовка отчёта (данных пока нет). Исследуются неодимовые магнитные шарики
(магнитный момент двумя методами, намагниченность, остаточная индукция),
по ним измеряются горизонтальная $B_\parallel$ и вертикальная $B_\perp$
составляющие поля Земли и магнитное наклонение $\beta$.

```
3.1.3/
├── data/
│   ├── raw/          сырые данные — заполняются вручную во время работы
│   └── processed/    результат обработки — пишется скриптом, вручную не править
├── report/
│   ├── main.tex      отчёт
│   └── img/          скан журнала (journal.jpg)
└── scripts/
    ├── lab_utils.py      общие утилиты (пути, МНК, округление, results.tex)
    └── process_data.py   обработка сырых данных (в системе СГС)
```

## Порядок работы

1. Заполнить таблицы в `data/raw/` (номера измерений и значения `n` уже
   проставлены) и погрешности приборов/широту в `setup_params.csv`.
2. `python scripts/process_data.py` — пишет таблицы, `fit_results.csv`,
   `results.tex` и прямые МНК для графиков (`fit_T.csv`, `fit_M.csv`).
   Константа `M_DIP_METHOD` в начале скрипта выбирает, какой магнитный
   момент шарика (метод А, Б или среднее) используется в частях II–III.
3. `cd report && latexmk -pdf main.tex` — числа и графики подставляются сами,
   недостающее выводится как **???**, выводы — «?? НЕОБХОДИМО ЗАПОЛНИТЬ ??».
   Справочные значения поля Земли (WMM/IGRF) вписать в табл. сравнения вручную.
