# 3.6.1 — Спектральный анализ электрических сигналов

Отчёт, данные измерений и скрипты обработки.

Источники данных:

- **части А и Б (количественные таблицы)** — измерения другой бригады на той же
  установке, используются с согласия автора и преподавателя
  (`data/raw/harmonics.csv`, `spectrum_width.csv`, `harmonics_spacing.csv`,
  `bursts.csv`); спектрограммы на рисунках частей А и Б — собственные;
- **меандр, часть Г (АМ), часть Е (RC)** — собственные скриншоты PicoScope
  (`report/img/*.png`), числа сняты с них скриптом `digitize_screens.py`
  (`data/raw/screens/`).

## Порядок работы

```bash
cd 3.6.1
python scripts/digitize_screens.py   # один раз; существующие файлы не перезаписывает (--force)
python scripts/process_data.py       # -> data/processed/*.csv, fit_macros.tex
python scripts/plot_data.py          # -> report/img/fig_*.pdf (необязательно)
cd report && latexmk -pdf main.tex
```

Все числа в тексте отчёта берутся из `data/processed/fit_macros.tex`,
таблицы и графики pgfplots — из `data/processed/*.csv`, поэтому после
повторной обработки достаточно пересобрать PDF.

## Оцифровка скриншотов

Калибровка осей (положения крайних линий сетки и подписи к ним) задана в
словаре `SCREENS` в `digitize_screens.py`. Погрешность отсчёта — 1 пиксель
(по частоте 6 Гц … 0,75 кГц, по амплитуде 0,02 … 1,5 мВ в зависимости от
масштаба экрана). Линии, упирающиеся в верхнюю границу экрана, помечаются
`clipped = 1` и в аппроксимацию амплитуд не входят.

## Замечания к данным

- В серии δν(1/T) точка T = 2τ (меандр) даёт δν = 2/T: чётные гармоники
  отсутствуют, видимые линии идут через одну. В аппроксимацию не входит.
- Погрешность Δν — половина шага гармоник δν/2: нуль огибающей находится
  только с точностью до ближайшей гармоники.
- В серии цугов с изменением ν₀ использованы ν₀ = 30, 40, 50 кГц
  (Δν = 6, 8, 10 кГц = ν₀/N).
- `spectrum_rect_nu4.png` снят при ν_повт = 5 кГц; `spectrum_am_wide_*.png` —
  спектры меандра 50 и 100 кГц (часть А, наложение частот);
  `spectrum_burst_nu100_N10.png` соответствует N = 5.
- `spectrum_am.png` снят при m ≈ 1; других спектров АМ нет, поэтому
  зависимость a_бок/a_осн(m) не строится.
