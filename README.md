# labs_lpr

Репозиторий с лабораторными работами по физике. Каждая лабораторная работа
оформлена в отдельной папке, названной по номеру работы в формате
**`раздел.подраздел.номер`** (например, `1.1.1`, `1.1.2`, `1.2.1`).

Внутри каждой лабораторной используется единый стек:

- **LaTeX** — оформление отчёта;
- **Python** — обработка экспериментальных данных, построение графиков;
- **C++** — расчёты/моделирование, где важна производительность;
- **data** — исходные и обработанные данные эксперимента.

## Структура репозитория

```
labs_lpr/
├── README.md                 # этот файл
├── common/                   # общие для всех лабораторных файлы
│   ├── latex_template/
│   │   └── preamble.tex      # общий LaTeX-преамбул (пакеты, поля, шрифты)
│   └── scripts/
│       └── plotting.py       # общие функции обработки данных и графиков
├── docs/                     # дополнительная документация (методички, справочные материалы)
├── 1.1.1/
│   ├── README.md             # краткое описание конкретной лабораторной
│   ├── report/
│   │   ├── main.tex          # исходник отчёта в LaTeX
│   │   └── images/           # рисунки и графики для отчёта
│   ├── src/
│   │   ├── main.cpp          # код на C++
│   │   └── CMakeLists.txt
│   ├── scripts/
│   │   ├── process_data.py   # обработка данных на Python
│   │   └── requirements.txt
│   └── data/
│       ├── raw/               # исходные (сырые) данные измерений
│       └── processed/         # обработанные данные, готовые для отчёта
├── 1.1.2/                     # структура аналогична 1.1.1
│   └── ...
├── 1.2.1/                     # структура аналогична 1.1.1
│   └── ...
└── ...
```

Каждая новая лабораторная добавляется отдельной папкой на верхнем уровне
репозитория с именем вида `x.x.x`, внутренняя структура — та же, что у
`1.1.1`.

## Как работать с лабораторной

На примере `1.1.1` (для остальных — аналогично, меняется только имя папки):

1. **Сырые данные** эксперимента кладутся в `1.1.1/data/raw/`.
2. **Обработка данных** выполняется Python-скриптом:
   ```bash
   cd 1.1.1/scripts
   pip install -r requirements.txt
   python process_data.py
   ```
   Скрипт читает `data/raw/`, считает результат и сохраняет его в
   `data/processed/`, а графики — в `report/images/`.
3. При необходимости тяжёлые расчёты/моделирование выполняются в C++:
   ```bash
   cd 1.1.1/src
   mkdir -p build && cd build
   cmake ..
   cmake --build .
   ./lab_1_1_1
   ```
4. **Отчёт** собирается из `1.1.1/report/main.tex`:
   ```bash
   cd 1.1.1/report
   pdflatex main.tex
   pdflatex main.tex
   ```

## Общие файлы (`common/`)

- `common/latex_template/preamble.tex` — единый преамбул для всех отчётов
  (пакеты, поля страницы, кодировка), подключается из `report/main.tex`
  командой `\input{../../common/latex_template/preamble.tex}`.
- `common/scripts/plotting.py` — переиспользуемые функции обработки данных
  и построения графиков (линейная аппроксимация МНК, единый стиль графиков
  и т.д.), импортируются из `scripts/process_data.py` каждой лабораторной.

## Как добавить новую лабораторную работу

1. Скопировать структуру существующей папки, например:
   ```bash
   cp -r 1.2.1 1.2.2
   ```
2. Очистить `data/raw/`, `data/processed/`, `report/images/` от чужих данных
   (оставить только `.gitkeep`/`README.md`).
3. Обновить `1.2.2/report/main.tex` (номер и тему работы), `1.2.2/README.md`,
   а также `CMakeLists.txt` (имя цели сборки).
4. Добавить строку в таблицу «Список лабораторных работ» в этом файле.

## Технологии

- LaTeX (pdflatex / xelatex)
- Python 3.10+ (numpy, pandas, matplotlib, scipy)
- C++17, CMake ≥ 3.10
- CSV/TSV для хранения данных
