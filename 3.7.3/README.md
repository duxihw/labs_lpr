# 3.7.3 — Длинные линии

Отчёт, шаблоны таблиц для измерений и скрипты обработки. Отчёт написан
заранее (теория, установка, ход работы); места под данные — таблицы и
графики читаются из `data/processed/`, числа — из `data/processed/results.tex`.
До измерений отчёт собирается: таблицы пустые, вместо чисел `???`,
вместо осциллограмм — рамки с именем ожидаемого файла.

```
3.7.3/
├── data/
│   ├── raw/          сырые данные — заполняются вручную во время работы
│   └── processed/    результат обработки — пишется скриптом, вручную не править
├── report/
│   ├── main.tex      отчёт
│   └── img/          осциллограммы (и check_*.png от plot_data.py)
└── scripts/
    ├── lab_utils.py      пути, чтение/запись CSV, МНК
    ├── process_data.py   обработка -> data/processed/*.csv + results.tex
    └── plot_data.py      быстрые графики для проверки данных во время работы
```

## Порядок работы

1. Во время лабораторной заполнить таблицы в `data/raw/` (строки с `#` —
   описание столбцов) и `setup_params.csv` (длина кабеля `l_cable`,
   подобранное `R_match_model`, частоты серий `nu_dist_1..4`).
2. Обработка:

   ```bash
   cd 3.7.3
   python scripts/process_data.py   # -> data/processed/*.csv, results.tex, сводка в консоль
   python scripts/plot_data.py      # -> report/img/check_*.png (необязательно)
   ```
3. Скриншоты осциллографа положить в `report/img/`:
   `setup_cable.png`, `osc_sine_matched.png`, `osc_sine_open.png`,
   `osc_pulse_matched.png`, `osc_pulse_open.png`.
4. Сборка: `cd report && pdflatex main.tex && pdflatex main.tex`.
5. Дописать в `main.tex` все места `\fillme` (выводы, обсуждение) и `\qq`
   (дата, длина кабеля, режим нагрузки в п.5 модели).

## Форматы сырых таблиц

| файл | пункт | столбцы |
|---|---|---|
| `setup_params.csv` | — | `param,value,sigma,unit,comment` |
| `cable_resonances.csv` | I (резонансы кабеля) | `signal,load,n,nu_MHz` (`signal`: sine/pulse, `load`: matched/open) |
| `afc_pfc.csv` | II (АЧХ, ФЧХ) | `nu_MHz,U0_V,Un_V,dx_ns,m` |
| `model_phase.csv` | модель, п.3 | `nu_kHz,dt_us,m` (сдвиг через `links_phase` = 5 звеньев, `m` — целые периоды) |
| `model_resonances.csv` | модель, п.4 | `load,n,nu_kHz` (`load`: short/open) |
| `model_distribution.csv` | модель, п.5 | `cell,U1_mV,U2_mV,U3_mV,U4_mV` |

## Замечания

- Все расчёты — в СИ (формулы методички в СГС переписаны, см. шапку
  `process_data.py` и раздел «Теоретические сведения» отчёта).
- `m` в `afc_pfc.csv` — число целых периодов, добавляемых к измеренному
  сдвигу `dx` (`Δφ = 2π(ν·dx + m)`); при `l ≈ 50 м` растёт на 1 примерно
  каждые 4 МГц. Проверять по монотонности ФЧХ.
- Множитель `p` в `V = p·l·Δν` (`P_FACTOR` в `process_data.py`) равен 1
  во всех режимах — опыт показал, что резонансы при 50 Ом и 1 МОм совпадают.
- Пункт 6* (резонансные кривые, добротность) не выполнялся и из отчёта убран.
- Теоретические резонансы модели считаются в предположении, что вход
  (генератор, 50 Ом ≪ R₀ ≈ 179 Ом) закорочен для стоячей волны.
