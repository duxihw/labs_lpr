# 3.3.5. Эффект Холла в металлах

Черновик до измерений. Источник — практикум, том 2, с. 183–187, формулы (3.27)–(3.29) и таблица 6 приложения. Основной образец — Cu или Ag; второй — Zn. В пункте 19 и таблице 6 различаются знаки постоянной Холла цинка. В журнале нужно сохранить схему подключения и знаковые показания.

| Файл в `data/raw/` | Содержание |
|---|---|
| `calibration.csv` | Не менее 15 точек возрастающей ветви, ток магнита в А и индукция в мТл либо изменение потокосцепления в мВб при извлечении катушки. |
| `series.csv` | Уникальное имя серии, материал, ток образца в А и собственный нуль серии в мкВ. |
| `hall.csv` | Имя серии, направление поля, модуль тока магнита, знаковое напряжение в мкВ в фиксированной полярности. Обратную ветвь связывать с той же серией, если использован тот же нуль. |
| `resistivity.csv` | По одному продольному измерению вне поля для каждого образца, ток в А и напряжение в мВ. |
| `setup_params.csv` | Для каждого материала размеры в мм и знак ориентации контактов, для пробной катушки произведение площади на число витков в м². |

Из папки работы:

```sh
python scripts/process_data.py
cd report
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Нужны NumPy, pandas и Matplotlib. Заголовки CSV и значащие нули сохранять; десятичный разделитель — точка. При известной абсолютной стандартной неопределённости добавьте в файл измерений столбец `d_<столбец>`; для параметра установки — отдельную строку `d_<имя>`. Такая величина заменяет обе составляющие по умолчанию. Для вычисления знака заполните `<материал>_orientation` по схеме в отчёте. Отсутствие ориентации оставляет знаковый результат открытым.

Поле интерполируется в пределах градуировки. По прямым ветвям Cu/Ag скрипт определяет наклон зависимости k(I), для Zn использует k/I. При h в метрах и напряжении в вольтах постоянная Холла равна произведению этого коэффициента на h и знак ориентации. Из продольного измерения вычисляется ρ = |U₃₄|ah/(|I|l), далее σ = 1/ρ, n = 1/(e|R_H|), μ = σ|R_H|. Графики сохраняются в `report/img/`, наклоны и итоговые макросы — в `data/processed/`. Дата, соавтор, паспортные характеристики и выводы по журналу заполняются в отчёте после опыта.
