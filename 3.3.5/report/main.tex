\section*{Аннотация}
По поперечному напряжению в металлической пластинке с током определяется постоянная Холла. Для основного образца (медь или серебро) используются серии при нескольких токах, для цинка --- одна серия при максимальном токе. Продольное падение напряжения даёт независимое измерение удельной проводимости. Совместно эти данные позволяют оценить холловскую концентрацию и подвижность носителей.

\section{Теоретические сведения}
Выберем ось $x$ вдоль тока образца $I$, ось $z$ вдоль прямого поля и ось $y$ так, чтобы система была правой. В стационарном состоянии поперечное электрическое поле уравновешивает магнитную составляющую силы Лоренца. Для одного типа носителей с зарядом $q$, концентрацией $n$ и дрейфовой скоростью $v_x$ имеем
\[
 q(E_y-v_xB_z)=0,\qquad j_x=nqv_x=\frac{I}{ah}.
\]
При ширине пластинки $a$ и толщине $h$ получаем
\begin{equation}
 U_H\equiv aE_y=R_H\frac{IB_z}{h},\qquad R_H=\frac{1}{nq}.
 \label{eq:hall}
\end{equation}
В этой системе $U_H$ равно потенциалу края при меньшем $y$ минус потенциал противоположного края. Для перехода от показаний прибора введём множитель $s=\pm1$, определяемый по положению контактов и полярности включения. Напряжения $U_{24}$ ниже приведены к одной полярности, в том числе после переключения К2.
\begin{equation}
 u=U_{24}(B)-U_{24}(0),\qquad U_H=s u,\qquad
 u_{\mathrm{odd}}(B)=\frac{U_{24}(+B)-U_{24}(-B)}{2}.
 \label{eq:odd}
\end{equation}
Вычитание нуля устраняет подмешивание продольного напряжения из-за смещения поперечных контактов. Полуразность при равных модулях поля дополнительно устраняет чётный по полю вклад. Продольное напряжение $U_{34}$ измеряется отдельно при $B=0$. Если $l$ --- расстояние между контактами 3 и 4, то
\begin{equation}
 \rho_0=\frac{|U_{34}|ah}{|I|l},\quad \sigma_0=\rho_0^{-1},\quad
 n_H=\frac{1}{e|R_H|},\quad \mu_H=|R_H|\sigma_0.
 \label{eq:transport}
\end{equation}
В многозонном металле $n_H$ и $\mu_H$ характеризуют холловский отклик. Отождествление их с микроскопическими параметрами носителей требует однозонного приближения.

\section{Методика измерений}
\begin{enumerate}
\item Проверить регулировку тока медного или серебряного образца и диапазон тока магнита при К1 в положении I. Записать допустимые токи с установки.
\item При медленном увеличении $I_\text{М}$ снять не менее 15 точек во всём диапазоне. Измерять $B$ непосредственно либо по изменению потокосцепления при извлечении катушки: $B=|\Delta\Phi|/(SN)$. Значение $SN$ снять с держателя.
\item Вставить основной образец в зазор выключенного магнита. При фиксированном $I$ измерить $U_0=U_{24}(0)$. Снять 5--7 значений $U_{24}$ при плавном нарастании поля. Резкое изменение потока наводит ЭДС в измерительных проводах.
\item Повторить серию для 5--7 значений $I$, каждый раз заново измеряя $U_0$. При максимальном $I$ снять также обратную ветвь при тех же модулях поля. Для цинка измерить $U_0$ и одну серию при максимальном токе.
\item Для обоих держателей зарисовать ток, направление поля по стрелке на магните и положению К1, расположение контактов и полярность прибора. Отметить направление силы $q\mathbf v\times\mathbf B$ и край с повышенным потенциалом. Определить $s$ по \cref{fig:contacts} с учётом реального монтажа.
\item Вынуть каждый образец из зазора, перевести К3 на $U_{34}$ и при токе порядка максимального записать $I$ и $U_{34}$. При смене предела записать новую цену деления.
\end{enumerate}

\paragraph{Погрешности.}
При отсутствии паспортных данных для показания $X$ используем приборную составляющую $0{,}03|X|$ и отсчёт в одну единицу последнего записанного разряда. Для распространения принимаем их за стандартные неопределённости. Скрипт варьирует отсчёты независимо, а масштаб одного прибора, калибровочные точки, $U_0$ одной серии и размеры одного образца использует согласованно во всех зависимых величинах. В каждом из 4000 вариантов повторяется МНК; разброс результатов даёт абсолютную погрешность. Для интерполяции используется линеаризация на выбранном интервале. Такой расчёт описывает погрешности входных данных; возможный гистерезис магнита и нелинейность проверяют по остаткам и обратной ветви.

В п.~19 методички поставлен вопрос об отрицательном $R_H$ цинка. В слабом поле для электронной и дырочной групп с концентрациями $n,p$ и подвижностями $\mu_e,\mu_h$ двухносительная модель даёт
\[
 R_H=\frac{p\mu_h^2-n\mu_e^2}{e(p\mu_h+n\mu_e)^2}.
\]
Отрицательный знак возможен при $n\mu_e^2>p\mu_h^2$, положительный --- при обратном неравенстве. Таблица 6 указывает для цинка положительный знак, что противоречит формулировке п.~19. Поэтому знак для данного держателя определяют по ориентации и измеренному наклону; одного подсчёта валентных электронов для его объяснения недостаточно.
