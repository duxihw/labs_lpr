## Что записать во время работы

| файл | пункт | что |
|------|-------|-----|
| `setup_params.csv` | п.11 | `N`, `N'`, `D`, `d` тора; `N_с`, `N'_с`, `l_с`, `d_с`, `R_с` соленоида; `R_М`, `R'_М`, `R_0` |
| `loop.csv` | п.5 | по строке на каждый щелчок: ветвь (`down`/`up`), ток **со знаком** после щелчка, отброс |
| `calib.csv` | п.8 | `ΔI_с = I_max` и отброс `Δx_с` (можно несколько повторов) |
| `initial.csv` | п.10 | ток после щелчка и отброс, от минимального тока до `I_max` |

Формат `loop.csv`: первая строка каждой ветви — стартовая точка (`C` или
`C'`) с пустым `dx`. При размыкании П1 вблизи `E` записывается строка с
`I_mA = 0`, следующая (замыкание П1 в обратном направлении) — уже с
отрицательным током. Пример:

```
branch,I_mA,dx
down,2000,
down,1500,0.4
...
down,40,30.5
down,0,42.0
down,-40,55.1
...
down,-2000,0.1
up,-2000,
up,-1500,0.4
...
```

Индукция в начальной точке каждой ветви берётся равной половине суммы
отбросов по этой ветви (петля симметрична); совпадение сумм по двум
ветвям проверяется скриптом (допуск 10 %).
