Отчёты по лабораторным работам по общей физике (МФТИ, 2-й курс, «Электричество
и магнетизм»). Автор — Емельянов Дмитрий Алексеевич, группа Б02-502.
Общаемся и пишем отчёты **по-русски**.

Раньше отчёты делались в проекте claude.ai; теперь работаем в Codex:
**одна сессия = одна лабораторная** (папка `x.x.x`). В сессии трогаем только
файлы своей папки, `common/` и `.github/` — только по явной просьбе.

## Перед любой работой: `git pull`

GitHub Actions (`.github/workflows/build-reports.yml`) после каждого push в
`main` сам пересобирает изменённые работы и **коммитит в `main`**
`report/<номер>.pdf` и `data/processed/` (коммиты «Сборка отчётов … [skip ci]»
от `github-actions[bot]`). Поэтому:

1. В начале сессии — `git pull --ff-only` (облако считаем источником истины).
2. Коммитим только исходники: `report/main.tex`, `report/img/*`, `data/raw/*`,
   `scripts/*`, `README.md`. Локально пересобранные `report/*.pdf` и
   `data/processed/*` перед коммитом откатываем (`git restore <пути>`) — их
   сделает CI. Иначе будут конфликты (как 29.10).
3. Перед push — `git pull --rebase`, потом `git push origin HEAD:main`
   (или PR в `main`; CI запускается только на `main`). После push через пару
   минут снова `git pull`, чтобы забрать PDF от CI.
4. Коммитим и пушим только когда пользователь просит.

## Локальное окружение (Windows)

- LaTeX: TeX Live 2026 из MSYS2, `D:\msys2\ucrt64\bin` (`pdflatex`, `xelatex`,
  `latexmk`, `tlmgr`) — в PATH. Сборка отчёта ~40 с.
- Python 3.14 с numpy, pandas, matplotlib, scipy (`python` в PATH).
- Скрипты удобнее гонять через Bash-инструмент (Git Bash). `gh` не установлен.
- Список пакетов TeX Live, которые нужны в CI, — в `build-reports.yml`; если
  добавляешь в отчёт новый пакет, проверь, что он есть в этом списке
  (иначе в CI отчёт не соберётся).

## Сборка одной работы

```bash
cd 3.4.5

cd report && latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

То же, что делает CI (с копированием в `report/345.pdf`):

`report/main.pdf` не коммитим (исключение — исторически отслеживаемый
`3.7.3/report/main.pdf`).

## Структура работы (актуальная, по образцу 3.4.5 / 3.7.3)

```
x.x.x/
├── README.md              статус работы, таблица файлов data/raw, формулы
├── data/raw/*.csv         данные из лабораторного журнала; строки с # — комментарии/описание столбцов
├── data/raw/setup_params.csv   параметры установки (name,value,...)
├── data/processed/        пишется ТОЛЬКО скриптом, руками не править
│   └── results.tex        макросы с итоговыми числами
├── scripts/
│   ├── lab_utils.py       копия общей утилиты: read_raw, write_processed, read_params,
│   │                      lsq / lsq_origin (МНК с погрешностями), TexResults, Results, tex_num
│   └── process_data.py    обработка конкретной работы (запуск из папки работы)
└── report/
    ├── main.tex           отчёт; \input{../../common/latex_template/preamble.tex}
    ├── img/               фото установки, сканы, внешние картинки
    └── <номер>.pdf        собранный отчёт (кладёт CI)
```

Принятые в отчётах приёмы (см. начало `3.4.5/report/main.tex`):

- Отчёт пишется **до измерений**: теория, установка, методика, обработка и
  выводы готовы, на месте чисел — `\qq` (`???`), на месте фото — заглушка
  `\labimage{file}{width}`. После лабы заполняем `data/raw/*.csv`, запускаем
  скрипт, пересобираем — таблицы/графики/числа подставляются сами.
- Числа в тексте: `\res{ключ}` из `data/processed/results.tex` (через
  `TexResults` в скрипте); нет значения → `???`.
- Таблицы — `tabularray`/`csvsimple-l3` из CSV; графики — `pgfplots`
  прямо из `data/processed/*.csv` (десятичная запятая: `use comma`), а не PNG
  из matplotlib.
- Схемы — `circuitikz`/TikZ. Ссылки — `cleveref` (`\cref`).
- Колонтитул: логотип МФТИ слева, фамилии соавторов справа; титульный лист —
  ФИО, группа, дата, «г. Долгопрудный». Соавторы и дата меняются от работы к
  работе — уточнять у пользователя.

## Требования к отчёту (кафедра общей физики)

Полный текст — `docs/requirements18.pdf` (на самом деле zip: `unzip -p docs/requirements18.pdf 1.txt 2.txt`).
Кратко:
- Разделы: аннотация, теоретические сведения, методика измерений, оборудование
  (с инструментальными погрешностями), результаты и обработка, обсуждение,
  заключение.
- Таблицы и графики с подписями; у осей/столбцов — обозначение и размерность.
- Точки с крестами погрешностей, не соединять линиями; теоретическая кривая —
  тонкой линией, параметры МНК с погрешностями — в тексте/легенде.
- Окончательные результаты — с абсолютной и относительной погрешностью,
  округление по правилам.

## Методички

- `docs/laboratornyj-praktikum-…-tom-2-elektrichestvo-i-magnetizm-….pdf` —
  **не PDF, а текст** (экспорт из проекта claude.ai). Найти работу:
  `grep -n '^Работа 3.4.5$' docs/laboratornyj*.pdf`, дальше читать с этой
  строки (`sed -n 'N,Mp'`). Оглавление — первые ~200 строк.
- Работы, которых нет в томе 2, — методичка лежит в папке работы как настоящий
  PDF (`3.6.1/3.6.1-2023.pdf`, `3.7.3/Длинные линии 08.pdf`).

## Новая лабораторная

1. `git pull`. Создать `x.x.x/` по структуре выше; `lab_utils.py` и каркас
   `main.tex` (преамбула, служебные макросы, колонтитул, титульный лист)
   взять из последней работы (3.4.5), содержание — из методички.
2. Сделать `data/raw/*.csv`-шаблоны с комментариями `#` под каждый пункт
   задания, `process_data.py`, отчёт с `???`, `README.md` работы.
3. Собрать локально, убедиться, что собирается и без данных.
4. Добавить строку в таблицу работ в корневом `README.md`.
