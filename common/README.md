# common/

Общие файлы, переиспользуемые во всех лабораторных работах.

- `latex_template/` — общий LaTeX-преамбул и стили оформления отчётов.
- `scripts/` — вспомогательные Python-скрипты (например, общие функции обработки данных, построения графиков, МНК и т.д.), которые используются в нескольких лабораторных.
