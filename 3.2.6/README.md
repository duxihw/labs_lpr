# 3.2.6 — Изучение гальванометра

Изучение высокочувствительного зеркального гальванометра магнитоэлектрической
системы: стационарный режим (измерение постоянного тока) и баллистический
режим (измерение заряда). Определяются динамическая постоянная $C_I$,
баллистическая постоянная $C_q^{kp}$ и критическое сопротивление $R_{kp}$
(тремя независимыми способами).

## Структура

- `report/main.tex` — отчёт (подключает общий преамбул из `common/`).
- `scripts/process_data.py` — считает критическое сопротивление $R_{kp}$ по
  данным декремента затухания, `data/raw` → `data/processed`.
- `data/raw/` — данные измерений в том виде, в котором они сняты в
  лабораторном журнале.
- `data/processed/` — данные после обработки скриптом, используемые
  непосредственно в таблицах отчёта.

## Как собрать

```bash
cd scripts
pip install -r requirements.txt
python process_data.py

cd ../report
pdflatex main.tex
pdflatex main.tex
```
