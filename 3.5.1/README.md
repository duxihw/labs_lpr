## Порядок работы

1. Во время работы заполнить `data/raw/*.csv` (строки с `#` — комментарии).
   Пока данных нет, PDF собирается с пустыми бланками таблиц — их можно
   распечатать и заполнять прямо на лабораторной.
2. Обработка:

   ```bash
   cd 3.5.1
   python scripts/process_data.py   # -> data/processed/*.csv, fit_results.csv, probe_family.tex
   python scripts/plot_data.py      # -> report/img/probe_1.pdf, probe_2.pdf, ...
   ```
3. Сборка: `cd report && pdflatex main.tex` (дважды).
4. Числа из `data/processed/fit_results.csv` и вывода скрипта перенести в
   текст вместо `???`.

## Форматы сырых таблиц

| файл | столбцы | что это |
|---|---|---|
| `setup_params.csv` | `param,value,sigma,unit,comment` | параметры установки (d, l зонда, делитель, R_б, U_заж …) |
| `discharge_iv.csv` | `branch,U_V1_V,I_mA` | ВАХ разряда, `branch` = `up`/`down` |
| `probe_iv.csv` | `Ip_mA,U_V,I_uA` | зондовые ВАХ, все токи разряда в одной таблице; U и I со знаком |

## Обработка

- `U_р = k_div · U_V1`; `R_диф` — локальная производная и МНК-наклон каждой ветви.
- Зондовые ВАХ: асимптоты по точкам `|U| > U_asym` (по умолчанию `0.5·U_max`),
  `I_iн` — полуразность их пересечений с осью `U = 0`; центрирование;
  наклон `dI/dU|0` — МНК по `|U| < U_lin` (по умолчанию `0.1·U_max`).
- `kT_e = I_iн / (2 dI/dU)` (эВ), контроль — аппроксимация `I = I_iн th(U/2T_e) + AU`.
- `n_e` по формуле Бома (`m_i` = 22 а.е.м.), `ω_p`, `r_De`, `r_D` (с `T_i` = 300 К),
  `N_D`, `α = n_e/n_0` при `P` = 2 торр.
