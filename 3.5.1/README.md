# 3.5.1 (4.16) — Изучение плазмы газового разряда в неоне

Измерения от 17 ноября 2026 г. В [основном отчёте](report/351.pdf) приведены стандартные ошибки по разбросу относительно прямых МНК. В [версии с описанием работы ИИ](report/351-ai.pdf) для тех же измерений дополнительно учтены погрешность отсчёта в одну единицу последнего записанного разряда и приборная погрешность 3 % от показания. В приложении описаны перенос исходных данных, пересчёт погрешностей и проверка результатов.

| Файл | Содержание |
| --- | --- |
| [discharge_iv.csv](data/raw/discharge_iv.csv) | 39 пар показаний для двух направлений изменения тока. Напряжение вольтметра до пересчёта делителя. |
| [probe_iv.csv](data/raw/probe_iv.csv) | 83 пары напряжения и тока двойного зонда. Знаки соответствуют положению переключателя П2. Принятые прочтения спорных цифр отмечены в таблице. |
| [setup_params.csv](data/raw/setup_params.csv) | Показание при зажигании и номиналы установки. Происхождение величин указано в комментариях. |

## Воспроизведение

Из папки работы, в окружении с NumPy, SciPy, pandas и TeX Live:

```sh
python scripts/process_data.py
python scripts/verify_results.py
python scripts/verify_ai_uncertainty.py
cd report
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

Локальная сборка создаёт `main.pdf` и `351-ai.pdf`. GitHub Actions публикует основной файл под именем `351.pdf`. Программа проверки заново находит параметры трёх прямых по исходным точкам, пересчитывает энергию, концентрацию и производные величины для всех режимов. Для разрядной характеристики она независимо определяет экстремумы наклонов.

На трубке принято $U=10U_1$. Для зондовых ВАХ применена графическая методика с линейной регрессией по центральному и двум крайним участкам. Сводные результаты, стандартные ошибки и проверки устойчивости находятся в [data/processed](data/processed). При 4,99 мА смена модели центрального участка меняет энергию электронов с 3,49 до 5,20 эВ. Паспортные погрешности приборов в исходных документах отсутствуют.

## Идентификация источников

Для версии ИИ пределы ошибок приняты равномерно распределёнными. Стандартная неопределённость показания вычисляется как `sqrt(digit² + (0.03*x)²)/sqrt(3)`. Каждая из четырёх приборных шкал общая для всех её показаний. Дополнительно учитывается прежний остаточный разброс регрессий. Номиналы геометрии зонда, делителя, давления и температуры ионов фиксированы. Бюджеты и межрежимные ковариации записаны в файлы `ai_*.csv`; отдельная программа проверяет их через возмущение исходных координат.

Автор подтвердил все десять первоначально спорных прочтений и параметры зонда. Исторические метки `uncertain` сохранены для воспроизведения ранее выполненной проверки. Фотография установки включена в версию с ИИ.
